This is already an excellent Minecraft-style SWMM UI. Here is a complete implementation guide organized by layer, covering everything visible in the screenshot plus deeper system design.

---

## Core Design Principles

The Minecraft aesthetic rests on four pillars:

- **Pixel grid** — everything snaps to an 8px or 16px grid
- **Chunky pixel font** — no smooth/anti-aliased typography
- **Block textures** — tiled bitmap-style backgrounds, no gradients
- **High contrast flat color** — no shadows, no blur, no glassmorphism

---

## 1. Typography

The most impactful single change. Load a pixel font and apply it everywhere:

```css
/* index.css */
@import url('https://fonts.googleapis.com/css2?family=Press+Start+2P&display=swap');

:root {
  --font-pixel: 'Press Start 2P', monospace;
}

* {
  font-family: var(--font-pixel) !important;
  /* Disable anti-aliasing for crisp pixels */
  -webkit-font-smoothing: none;
  image-rendering: pixelated;
}
```

Use`Press Start 2P` (Google Fonts, free) — this is exactly the font visible in the screenshot for "SWMM CRAFT ULTIMATE" and all labels. Size it small (8-10px) because the font is wide.

## 5. Hotbar (Bottom Toolbar — Slot System)

The hotbar in the screenshot is a direct copy of the Minecraft inventory hotbar. This is the tool selector:

```tsx
// Hotbar.tsx
const TOOLS = [
  { slot: 1, icon: "↖", label: "Select",    key: "select" },
  { slot: 2, icon: "✚", label: "Add Node",  key: "addNode" },
  { slot: 3, icon: "⬜", label: "Junction",  key: "junction" },
  { slot: 4, icon: "⬛", label: "Storage",   key: "storage" },
  { slot: 5, icon: "⬤", label: "Outfall",   key: "outfall" },
  { slot: 6, icon: "━━", label: "Conduit",   key: "conduit" },
  { slot: 7, icon: "◆",  label: "Subcatch",  key: "subcatch" },
  { slot: 8, icon: "🗑", label: "Delete",    key: "delete" },
  { slot: 9, icon: "◈",  label: "Raingage",  key: "raingage" },
];

export function Hotbar({ activeTool, onSelect }) {
  return (
    <div className="hotbar">
      {TOOLS.map((tool) => (
        <div
          key={tool.slot}
          className={`hotbar-slot ${activeTool === tool.key ? "active" : ""}`}
          onClick={() => onSelect(tool.key)}
          title={tool.label}
        >
          <span className="slot-number">{tool.slot}</span>
          <span className="slot-icon">{tool.icon}</span>
        </div>
      ))}
    </div>
  );
}
```

## 8. Minimap (Top-Right)

The minimap in the screenshot uses colored pixel dots on a dark background:

```tsx
// Minimap.tsx
export function Minimap({ nodes, links, viewport }) {
  const canvasRef = useRef<HTMLCanvasElement>(null);

  useEffect(() => {
    const ctx = canvasRef.current?.getContext("2d");
    if (!ctx) return;

    ctx.fillStyle = "#0a0a1a";
    ctx.fillRect(0, 0, 160, 120);

    // Draw nodes as 2x2 pixel blocks
    nodes.forEach((node) => {
      const mx = (node.x / worldWidth) * 160;
      const my = (node.y / worldHeight) * 120;
      ctx.fillStyle = NODE_COLORS[node.type];
      ctx.fillRect(Math.floor(mx), Math.floor(my), 2, 2);
    });

    // Draw viewport rectangle
    ctx.strokeStyle = "#ffffff";
    ctx.lineWidth = 1;
    ctx.strokeRect(
      (viewport.x / worldWidth) * 160,
      (viewport.y / worldHeight) * 120,
      (viewport.w / worldWidth) * 160,
      (viewport.h / worldHeight) * 120
    );
  }, [nodes, links, viewport]);

  return (
    <canvas
      ref={canvasRef}
      width={160} height={120}
      className="minimap-canvas"
    />
  );
}
```

For the pixel-art feel, snap all subcatchment vertices to the 32px grid:

```ts
function snapToGrid(vertices: Point[], gridSize = 32): Point[] {
  return vertices.map((v) => ({
    x: Math.round(v.x / gridSize) * gridSize,
    y: Math.round(v.y / gridSize) * gridSize,
  }));
}
```

## 12. Animation — Water Flow in Conduits

```ts
// Animate dashes along conduits to show flow direction
function animateFlowArrows(ctx: CanvasRenderingContext2D, conduit, flowRate) {
  const speed = flowRate * 0.1;  // pixels per frame
  const dashOffset = (Date.now() * speed / 1000) % 16;

  ctx.setLineDash([8, 8]);
  ctx.lineDashOffset = -dashOffset;
  ctx.strokeStyle = flowRate > 0 ? "#4488ff" : "#ff4444";
  ctx.lineWidth = 3;

  ctx.beginPath();
  ctx.moveTo(conduit.x1, conduit.y1);
  ctx.lineTo(conduit.x2, conduit.y2);
  ctx.stroke();

  ctx.setLineDash([]);  // reset
}
```
